# Accessibility Statement

The CoE-NNECT team is committed to ensuring digital accessibility for all users, including people with disabilities. We continually improve the user experience for everyone and apply the relevant accessibility standards.

## Conformance Status
The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities. 

We are actively working towards **WCAG 2.1 Level AA** conformance. Our current implementation includes:
- Sufficient color contrast ratios for primary text.
- Keyboard navigability for all major modals and forms.
- ARIA labels on icon-only buttons (e.g., close buttons, flag icons).
- Responsive design accommodating desktop, tablet, and mobile viewports.

## Known Limitations
- The interactive Timetable Grid (drag-and-drop) is optimized for mouse/touch interaction. We provide an alternative "Agenda View" and "Edit Modal" for users who prefer keyboard navigation.
- Some legacy PDF exports may not be fully screen-reader optimized.

## Reporting Accessibility Barriers
If you encounter accessibility barriers on CoE-NNECT, please open an issue using the GitHub Issue Tracker.
